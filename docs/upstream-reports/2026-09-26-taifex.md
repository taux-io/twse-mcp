- **回報者**：台股 MCP（twse-mcp，https://github.com/taux-io/twse-mcp）維護者
- **聯絡方式**：（請填寫）
- **查證時間**：2026-09-26 全日觀察；本文數據的最後一次核對為 15:49–15:58（台灣時間）
- **回報管道**：政府資料開放平臺各資料集頁面的「我有話要說」，或頁面所列的提供機關聯絡人
  （例：[期貨市場三大法人-總表-依日期](https://data.gov.tw/dataset/11592)）

`https://openapi.taifex.com.tw/v1/` 的 swagger 宣告各端點回傳 JSON。實際上有數個端點會在**沒有任何
請求差異的情況下**，時而回 JSON、時而回 CSV。依 swagger 串接的程式因此會間歇性失敗。以下三點各附重現方式。

---

## 一、同一端點在 JSON 與 CSV 之間來回切換

所有請求都帶相同的標頭（`Accept: application/json`），間隔 30～45 秒。

### 影響

依 swagger 以 JSON 解析的程式，會在端點切成 CSV 的期間失敗；而且失敗是間歇的，難以察覺也難以重現。

---

## 二、所有端點的 `Content-Type` 都是 `application/octet-stream`

不論回應實際是 JSON 還是 CSV，`Content-Type` 一律是 `application/octet-stream`。用戶端無法憑標頭判斷格式，
只能自己嗅探內容。

建議：JSON 回應標 `application/json; charset=utf-8`，CSV 回應標 `text/csv; charset=utf-8`。

---

## 三、CSV 帶 UTF-8 BOM，而且表頭與 swagger 的欄位說明不一致

CSV 開頭帶 UTF-8 BOM（位元組 `EF BB BF`）。另外，CSV 表頭的文字與 swagger 宣告的欄位說明有出入，
依 swagger 對應欄位的程式會對不上：

| 端點 | swagger 的欄位說明 | CSV 實際表頭 |
|---|---|---|
| `OpenInterestOfLargeTradersFutures` | 前五大交易人買方、前五大交易人賣方、前十大交易人買方、前十大交易人賣方 | 前五大交易人買方**數量**、前五大交易人賣方**數量**、前十大交易人買方**數量**、前十大交易人賣方**數量** |
| `DailyMarketReportFut` | 契約 | 契約**代號** |

---

## 重現方式

只需要 `curl` 與 POSIX shell。每 30 秒對六個端點各發一次請求，印出時間、端點、`Content-Type`、
回應前 3 個位元組（十六進位；`5b7b22` 是 JSON 的 `[{"`、`efbbbf` 是 UTF-8 BOM）與回應開頭文字：

```sh
#!/bin/sh
# 用法：sh taifex_poll.sh [輪數，預設 20]
ROUNDS=${1:-20}
EPS="MarketDataOfMajorInstitutionalTradersGeneralBytheDate FinalSettlementPrice OpenInterestOfLargeTradersFutures SSFAdjustedInfo DailyMarketReportFut DailyMarketReportOpt"
i=0
while [ "$i" -lt "$ROUNDS" ]; do
  for ep in $EPS; do
    curl -s -H 'Accept: application/json' -D hdr.txt -o body.bin "https://openapi.taifex.com.tw/v1/$ep"
    ctype=$(grep -i '^content-type:' hdr.txt | tr -d '\r' | cut -d' ' -f2-)
    first3=$(head -c 3 body.bin | od -An -tx1 | tr -d ' \n')
    text=$(head -c 60 body.bin | LC_ALL=C tr -d '\r\n')
    echo "$(date '+%Y-%m-%d %H:%M:%S') $ep | $ctype | $first3 | $text"
  done
  i=$((i + 1))
  [ "$i" -lt "$ROUNDS" ] && sleep 30
done
rm -f hdr.txt body.bin
```

```

2026-09-26 15:58:12 FinalSettlementPrice | application/octet-stream | efbbbf | 最後結算日,契約月份,商品代號,商品名稱,…
2026-09-26 15:58:12 DailyMarketReportFut | application/octet-stream | 5b7b22 | [{"Date":"20260924","Contract":"ZFF",…
```

格式切換是間歇的，一次輪詢可能看不到；建議跑 20 輪（約 10 分鐘）以上，或在不同時段各跑一次。

## 建議

1. 請確認這些端點背後是否有部分節點（或快取）回傳 CSV 下載檔、部分回傳 JSON，並讓 OpenAPI 端點穩定回 JSON。
2. 依實際格式設定 `Content-Type`。
3. 若 CSV 為正式提供的格式，請讓表頭與 swagger 的欄位說明一致，並考慮去除 BOM。
